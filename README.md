## 📝 자기소개 작성 규칙

### 1. 파일 위치
`members/` 폴더 안에 본인 파일을 생성합니다.

### 2. 파일명 규칙
위 명단에서 본인 이름에 해당하는 파일명을 사용하세요.

### 3. 내용 작성
`members/_template.md`를 복사해서 본인 내용으로 채우세요.
파일 맨 위 `# [본인 닉네임]` 부분을 **위 명단의 본인 이름**으로 바꿔주세요.
예: `# 강민석`

### 4. 다른 사람 파일은 건드리지 마세요
본인 파일만 추가하면 충돌 없이 작업할 수 있습니다.

## 🔀 PR 진행 순서

1. **레포를 풀(Pull) 받기**
   ```
   git clone https://github.com/selfishclub/intro-practice-0817.git
   ```

2. **본인 브랜치 생성**
   ```
   git checkout -b feat/{본인이름}-intro
   ```
   예: `feat/강민석-intro`

3. **`members/` 폴더에 본인 이름으로 파일 작성**
   `_template.md`를 복사해서 `members/{본인이름}.md`로 만들기

4. **커밋 + 푸시**
   ```
   git add members/{본인이름}.md
   git commit -m "[자기소개] {본인이름} 추가"
   git push origin feat/{본인이름}-intro
   ```

5. **Pull Request 생성**
   PR 제목: `[자기소개] {본인이름} 추가`

6. **본인이 본인 PR을 직접 머지** ⭐

> ⭐ 머지는 본인이 직접 합니다.
> 작업이 끝나면 바로 머지하세요.
