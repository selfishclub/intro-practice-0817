## 📝 자기소개 작성 규칙

### 1. 파일 위치
`members/` 폴더 안에 본인 파일을 생성합니다.

### 2. 파일명
`본인닉네임.md` — 본인이 쓰고 싶은 닉네임으로 자유롭게 만드세요.

### 3. 내용 작성
`members/_template.md`를 복사해서 본인 내용으로 채우세요.
파일 맨 위 `# [본인 닉네임]` 부분도 본인 닉네임으로 바꿔주세요.

### 4. 다른 사람 파일은 건드리지 마세요
본인 파일만 추가하면 충돌 없이 작업할 수 있습니다.

## 🔀 PR 진행 순서

1. 이 레포를 내 컴퓨터로 클론(복사)해주세요
2. 내 이름(닉네임)으로 브랜치를 만들어주세요
3. `members/` 폴더 안에 `_template.md`를 복사해서 내 닉네임으로 파일을 만들어주세요
4. 내용을 채워주세요
5. 저장하고 커밋해주세요
6. 푸시해주세요
7. GitHub에서 Pull Request를 만들어주세요
8. 본인이 직접 머지해주세요 ⭐

> ⭐ 머지는 본인이 직접 합니다.
> 작업이 끝나면 바로 머지하세요.
